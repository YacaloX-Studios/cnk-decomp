## Key recovered subsystems

### Core runtime
- `memcpy64` (`0x001071e0`, `core/mem`): 64-byte aligned copy (16 dwords).
- `heap_alloc_block` (`0x00534b60`, `core/mem`): fixed-pool sub-allocator —
  rounds sizes to alignment, carves from heap header (min size `+8`, used
  `+0x1c`, freelist `+0x20`); fail sentinel `DAT_006b6498`.
- `heap_stats` (`0x004311f0`, `core/mem`): walks 128 allocation lists, sums used
  (&~3 aligned) / free into `DAT_00657f0x`.
- `packed_bits_write` / `packed_bits_read` (`0x0010e780` / `0x0010ee50`,
  `core/bitstream`): LEB128/varint-style bit packing.
- `swap16` / `swap32` (`0x00530050` / `0x00530080`, `core/endian`): LE<->BE.

### Math
- VU0/COP2 macro-mode functions (21): matrix transforms, e.g. `0x00381030`,
  `0x00365d80`, `0x0035bc40`, `0x003f6840`, `0x003f6b20`, `0x001b6340`,
  `0x00190370`.
- Gauss-Jordan solver: `0x003a0730`, `0x003a09f0` (likely inverse / IK).
- `vec3_copy` / `lerp3` (`0x0015ba30` / `0x0058d7c0`, `math/vec`).

### Graphics
- `blit_palette_image` (`0x004518d0`, `gfx/image`): CLUT remap, in-place
  2/4/6/8/16 bpp indexed lookups.
- `pixel_format_convert` (`0x0058dea0`, `gfx/color`): RGBA -> float4, selects
  packing (ARGB/RGBA/BGRA/RGBx/BGRx/ABGR).
- Split-screen viewports: `0x0022ade0`, `0x0022d1a0`, `0x002304a0` (`ui/layout`).
- 4cc type checks: `0x0026d960`..`0x0026e420`.

### Gameplay
- Script / state machines: `0x0042a818`, `0x0042a4e0`, `0x0042bc88`,
  `0x0042a680`, `0x0042ac48` (`game/script`).
- Tuning tables (kart physics readouts): `0x0019e150`..`0x0019f7f0`,
  `0x00195820`, `0x001a1800` (`game/tuning`).
- Entity defaults: `0x0011e790` (`game/entity`) — 1.0f scales, 100/101 fov.

### Boot
- `boot_iop_copy` (`0x006588a0`, `sys/boot`): copies 0x26 bytes from IOP RAM
  (`0xbc0003c0` region) into EE low RAM, gated on an IOP boot flag.

## Heuristics for the ~358 unlabeled leaves

The remaining real functions are pure copy/accessor leaves. Naming heuristics by
signature shape:

1. **struct-copy** `void f(dst, src)` with no control flow and no arithmetic —
   `struct_copy_<N>` (N = byte width).
2. **accessor** `T f(struct*, ...)` returning one field — `get_<field>` /
   `set_<field>`.
3. **pair-wise** `void f(a, b)` writing 2–8 words — `copy_<N>_<M>`.
4. **small-table** — single `for` over a fixed range — `table_*`.

Use `inventory.csv`'s `body_bytes` to size the copy; leaves ≤ ~64 bytes with no
`if (`, no `float`, no `DAT_` are auto-tagged `core/struct` by
`tools/decomp_split.py`.
